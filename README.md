# 🎮  Tic-Tac-Toe

A fun and interactive **Tic-Tac-Toe game** built using Python and Streamlit, featuring a modern neon-style interface, glowing effects, and victory animations.

## ✨ Features

* 🎨 Modern neon-themed UI
* ❌⭕ Two-player Tic-Tac-Toe gameplay
* 🏆 Automatic winner detection
* 🤝 Draw detection
* 🎉 Victory animations
* 🔄 Restart game functionality
* 📱 Simple and user-friendly interface

## 🛠️ Technologies Used

* **Python** – Game logic
* **Streamlit** – Web application framework

## 🚀 How to Run Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd Neon-Tic-Tac-Toe
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The game will open in your web browser.

## 🎯 How to Play

1. Player 1 uses **❌ X** and Player 2 uses **⭕ O**.
2. Players take turns selecting an empty cell.
3. The first player to get three marks in a row, column, or diagonal wins.
4. If all cells are filled without a winner, the game ends in a draw.
5. Restart the game to play again.
